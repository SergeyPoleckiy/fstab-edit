# Changelog

Все значимые изменения проекта fstab-edit документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии проекта следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- GitHub Actions: CI (линт с пином golangci-lint, тесты с `-race`, порог
  покрытия ≥ 80 %, статическая сборка + smoke) на push/PR в `main` и `dev`;
  релизный workflow по тегам `v*` (сборка, `SHA256SUMS`, автоматические
  заметки релиза).
- Автодополнение устройств по PARTUUID/PARTLABEL (приоритет
  `UUID=` → `PARTUUID=` → `LABEL=` → `PARTLABEL=` → путь); повторяющиеся
  идентификаторы помечаются в панели подсказок.
- Пользовательская палитра TUI: ключ `tui.colors` (13 ролей, форматы
  hex `#rrggbb` / номер ANSI 0–255 / имя ANSI-цвета); отказ конфигурации
  при неизвестной роли или невалидном цвете (exit 2).
- Двуязычная документация: английский `README.md` (основной) с оглавлением,
  `README.ru.md`, английская версия руководства `docs/user-guide.en.md`,
  русская man-страница `docs/man/fstab-edit.ru.1`; `make pdf` собирает оба
  PDF, `make install` ставит обе man-страницы (выбор по локали).

## [1.3] — 2026-11-22

### Added

- Подсветка синтаксиса записей в таблице TUI: поля source, mount point, тип ФС
  и опции отображаются разными цветами (ТЗ §5.3).
- Цветовая подсветка ошибок и предупреждений: ошибки — красным, предупреждения —
  жёлтым; текстовые маркеры (`!`, `?`) сохраняются во всех темах (ТЗ §5.3, §9.6).
- Темы оформления TUI `light` и `high-contrast` (усиленная контрастность для
  плохого зрения и проектора); выбор через ключ `tui.theme` в конфигурации,
  всего четыре встроенные темы: `dark` (по умолчанию), `light`, `high-contrast`,
  `monochrome` (ТЗ §5.5, §13).
- Man-страница `fstab-edit(1)` (docs/man/fstab-edit.1) и цели `make install` /
  `make uninstall` для установки бинаря и man-страницы (переменные `PREFIX`,
  `DESTDIR`).
- CHANGELOG.md (этот файл) по формату Keep a Changelog.
- Примеры конфигурации: examples/config-minimal.yaml и examples/config-full.yaml.
- Документация для разработчиков docs/DEVELOPMENT.md: архитектура, сборка и
  тесты, стандарты кода, релизный процесс.

### Fixed

- `Ctrl+C` на подэкранах TUI (diff, монтирования, устройства, история, журнал,
  помощь, результат сохранения) теперь работает как `Esc`, а не вызывает
  неожиданный выход из программы.
- `i`/`Ins` на экране ошибки загрузки не открывает форму записи; статусная
  подсказка предлагает сначала исправить загрузку файла (F5).
- Экран истории (`H`) при несохранённых изменениях предупреждает, что restore
  приведёт к потере несохранённых изменений.
- Клавиша `r` на экране блочных устройств (`B`) перечитывает список устройств.
- Инвариант состояния TUI: ошибка загрузки target гарантирует отсутствие
  активной сессии редактирования (`loadErr ⇒ session == nil`).
- Статус ошибки загрузки не маскируется после неудачного reload при restore.

## [1.2] — 2026-11-22

### Added

- Интерактивный TUI-редактор на bubbletea (команда `fstab-edit tui` и запуск без
  аргументов): таблица записей, формы добавления и редактирования, undo,
  транзакционное сохранение через тот же `internal/transaction`, что и CLI.
- Экраны TUI: diff несохранённых изменений, статус монтирований (findmnt),
  блочные устройства (lsblk), история резервных копий с restore через
  доменный rollback, журнал операций, помощь.
- Парсеры `lsblk`/`blkid` и общий перечень известных типов ФС.
- Автодополнение в форме записи: устройства (приоритет `UUID=` → `LABEL=` →
  `/dev/...`), типы ФС и опции (набор зависит от типа ФС).
- Темы оформления TUI `dark` и `monochrome`, выбор через ключ `tui.theme`.
- Руководство пользователя docs/user-guide.md; PDF-версия собирается целью
  `make pdf` (pandoc + xelatex).

### Changed

- Версия бинаря выводится из git (`git describe --tags`) через Makefile;
  ручной ввод версии не требуется.
- README: добавлен раздел установки.

### Fixed

- Переключение комментария (`comment`/`uncomment`) и связанные правки i18n и
  статуса перезагрузки target.
- Прокрутка окна подсказок формы и уточнение автодополнения опций.

## [1.0] — 2026-11-21

### Added

- Первый релиз: ядро безопасного редактирования `/etc/fstab` и CLI.
- Lossless-парсер с побайтовым сохранением, модель документа и публичные
  модели данных (`pkg/models`).
- In-memory мутации документа: add, edit, delete, comment/uncomment (включая
  связанные блоки комментариев).
- Внутренний валидатор: проверка полей, source, mount point, типа ФС, опций,
  дубликатов и специальные предупреждения.
- Транзакционная запись: внутренняя валидация, flock, контроль base SHA-256,
  статическая проверка кандидата через `findmnt --verify`, backup операции,
  атомарный replace с сохранением metadata/xattrs, post-check и один
  automatic rollback.
- Резервные копии с sidecar-метаданными, верификацией и ротацией.
- CLI на Cobra: десять команд (`list`, `add`, `edit`, `delete`, `comment`,
  `uncomment`, `validate`, `verify-mount`, `backup`, `rollback`), dry-run,
  подтверждения `[y/N]`, unified diff, селекторы записей, форматы вывода
  `table`/`json`/`csv`/`tsv`, стабильные exit codes 0–8.
- YAML-конфигурация с приоритетами и security-checks, структурный JSON Lines
  журнал с rotation и redaction секретов, локализация RU/EN.
- Версия бинаря через `git describe`.
