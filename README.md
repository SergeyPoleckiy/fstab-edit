# fstab-edit

Утилита для безопасного редактирования `/etc/fstab` в Linux.

Проект предоставляет CLI для автоматизации и TUI для интерактивной работы. Основные требования: транзакционная запись, статическая проверка файла-кандидата, резервные копии, rollback и побайтовое сохранение неизменённого содержимого.

## Статус

- Текущий этап: **1 — ядро и CLI**.
- Go-модуль и исходный код пока не созданы.

## Безопасность при разработке

Никогда не используйте реальный `/etc/fstab` основной системы для разработки и ручных экспериментов. Все тесты должны работать с временными файлами и опцией `--file`; разрушительные и привилегированные проверки выполняются только в изолированных VM.

## Требования

- Go 1.22 или новее.
- Linux.
- Для обычных тестов root не требуется.
- `findmnt` обязателен для проверки перед сохранением.
- `blkid` и `lsblk` потребуются на этапе 3.
- `golangci-lint` используется для локальной проверки и CI.

## Первоначальная настройка

Перед первой сборкой необходимо создать Go-модуль и добавить зависимости:

```bash
go mod init fstab-edit
go get github.com/spf13/cobra
```

Команды сборки и проверки:

```bash
go build -o fstab-edit .
go test ./... -v
go test ./... -cover
golangci-lint run
```

## Документация по безопасности

Основные гарантии:

1. Перед записью создаётся проверенная резервная копия.
2. Проверка выполняется по файлу-кандидату до изменения оригинала.
3. Запись выполняется атомарно.
4. Конфликт с внешним изменением файла запрещает перезапись.
5. Ошибка после записи вызывает rollback копии текущей транзакции.
6. Резервная копия гарантирует восстановление исходных байтов, но не работоспособность уже повреждённой исходной конфигурации.
