# fstab-edit

Утилита для безопасного редактирования `/etc/fstab` в Linux.

Проект утилиты с будущими CLI для автоматизации и TUI для интерактивной работы. Основные требования: транзакционная запись, статическая проверка файла-кандидата, резервные копии, rollback и побайтовое сохранение неизменённого содержимого.

## Статус

- Текущий этап: **1 — ядро и CLI**.
- Реализованы модель данных, lossless parser, selectors и in-memory mutations: Add, Edit, Delete, Comment и Uncomment, включая связанные comment blocks.
- CLI и исполняемый файл ещё не созданы. Операции работают только с документом в памяти и не изменяют `/etc/fstab`.
- Актуальная основа разработки: [ТЗ версии 2.0](../fstab-editor-v2.md).
- Исходная редакция сохранена: [ТЗ версии 1.0](../fstab-editor.md).

## Безопасность при разработке

Никогда не используйте реальный `/etc/fstab` основной системы для разработки и ручных экспериментов. Текущие тесты работают только с документами в памяти. После появления CLI файловые тесты должны использовать временные файлы и опцию `--file`; разрушительные и привилегированные проверки выполняются только в изолированных VM.

## Требования

- Go 1.22 или новее.
- Linux.
- Для обычных тестов root не требуется.
- `findmnt` обязателен для проверки перед сохранением.
- `blkid` и `lsblk` потребуются на этапе 3.
- `golangci-lint` используется для локальной проверки и CI.

## Документация по безопасности

Основные гарантии:

1. Перед записью создаётся проверенная резервная копия.
2. Проверка выполняется по файлу-кандидату до изменения оригинала.
3. Запись выполняется атомарно.
4. Конфликт с внешним изменением файла запрещает перезапись.
5. Ошибка после записи вызывает rollback копии текущей транзакции.
6. Резервная копия гарантирует восстановление исходных байтов, но не работоспособность уже повреждённой исходной конфигурации.
